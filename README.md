# Lefon Lucro Web

Distribuição Flutter Web/PWA de um aplicativo de gestão para revendedores: lucro por venda, estoque, fiado e caixa.

## Distribuição

Este repositório contém arquivos compilados, incluindo `main.dart.js`, recursos em `assets/`, inicialização Flutter e service worker. Ele não contém o projeto Flutter completo.

O código-fonte é mantido em repositório privado, conforme a descrição deste projeto. A disponibilidade pública deste build não implica que todo o código-fonte seja aberto.

## Manutenção

Gere as alterações a partir do projeto Flutter de origem. Preserve os arquivos de avisos e licenças em `assets/NOTICES` e junto às fontes ao atualizar a distribuição.

O `index.html` usa a base `/lefon-lucro-web/`; alterações no caminho de hospedagem exigem um build ou configuração compatível.
